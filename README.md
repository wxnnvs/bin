# Bin

a truely minimal paste app

---

### Usage (Docker)

1. Clone this repo
2. run `docker compose up -d`
3. Wait
4. **Profit!** (port 3000)

### Usage (Manual)

1. Clone this repo
2. run `pnpm install`
3. Run `pnpm dev`
4. **Profit!** (port 3000)

---

it uses plain text files and simple html templating to serve your text content.
